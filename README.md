# 🎬 Video Editor

A browser-based video editor inspired by the simplicity and workflow of modern editing tools.

![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Overview

Video Editor is a lightweight browser-based video editing application that allows users to edit videos without installing heavy desktop software.

The goal of this project is to provide an intuitive editing experience similar to CapCut while remaining simple, fast, and easy to deploy.

---

## 🚀 Features

- 🎞️ Timeline-based editing
- ✂️ Trim video clips
- 🖼️ Image support
- 🎵 Audio support
- 📂 Drag & Drop media import
- ⚡ Fast browser rendering
- 💾 Local project support
- 🌐 Browser-based (No installation required)

## 🛠️ Installation

Clone the repository

```bash
git clone https://github.com/alphabat81/video-editor.git
```

Move into the project

```bash
cd video-editor
```

Install dependencies

```bash
npm install
```

Start the server

```bash
node server.js
```

or

```bash
npm start
```

---

## 💻 Local Development

Windows

